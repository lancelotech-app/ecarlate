Features

Everything video needs, in one place.

No plugin ecosystem. No account. No cloud sync. Just a focused set of tools that make video usable for actual work.

📚

A real library

Real thumbnails, duration, resolution. Filters, favorites, collections. Search by name — or by dialogue.

🎬

A keyboard-first player

Every control bound to a shortcut you can rebind. Hover thumbnails on the timeline. Chapters, scenes, markers.

💬

Subtitles that work

SRT, VTT, ASS, SSA. Auto-found next to your video. Adjust size, color, offset, position — in real time.

🗣️

Local Whisper transcripts

🔍

Search inside dialogue

Find that one line across your entire library. Click a hit, jump straight to the exact second.

Study with notes

Timestamped notes per video. Every note remembers when you wrote it. Click to seek back.

FAQ

Questions, answered.

Is ECARLATE really free?
Yes. Completely free and open source. No paid tiers, no feature locks, no watermarks. If you find it useful, you can donate to the developer from the About section — but it's never required.
Does it send my videos anywhere?
No. Everything — video decoding, transcription, search, thumbnails — runs locally. ECARLATE makes zero outbound network calls except when you explicitly download a Whisper model.
What video formats are supported?
MP4, WebM, MKV, AVI, MOV, FLV, WMV, M4V, OGV, MPG, MPEG, TS, M2TS. Formats that the WebView can't play natively are transcoded on the fly using bundled ffmpeg — with no visible delay once the first frame decodes.
Do I need to install ffmpeg separately?
No. ffmpeg and ffprobe are bundled inside the installer. Everything works out of the box.
How does Whisper transcription work offline?
ECARLATE uses whisper.cpp compiled directly into the app. When you click Transcribe for the first time, it downloads the model you picked (from 75 MB for Tiny to 1.5 GB for Medium). After that, all transcription happens on your CPU, no internet required. Models are stored in your app data folder.
Will it run on macOS or Linux?
Not yet — 1.0.0 is Windows-only. macOS and Linux builds are on the roadmap for a future 1.x release. The codebase is already cross-platform (Tauri + Rust); only the installer and platform-specific integrations (like SMTC) are Windows-focused in this release.
Where is my data stored?
On Windows: %APPDATA%\com.ecarlate.app\. You'll find a single SQLite database (ecarlate.db), the downloaded Whisper models, and a thumbnail cache folder. Everything is yours. Back it up, move it, delete it — no server involved.
Can I contribute?
Absolutely. The GitHub repository is public — open issues for bugs, submit pull requests, or fork it for your own needs. MIT license, so you can do whatever you want with it.
